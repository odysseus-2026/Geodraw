# Geodraw
做一个纯网页版的几何自动作图工具。输入一道几何题的文字（支持语音输入、 拍照 OCR 识别），程序自动理解题目、绘制对应的平面图形或三维立体图形， 三维图形可在浏览器中自由旋转、缩放、平移；识别不了的题目自动进入"待升级队列"， 导出后交给 AI 扩充规则库，形成可持续迭代闭环。
**为谁解决什么具体问题**：

- **高中生**：做立体几何题时"脑中没有图"，手工画图慢且不准——输入题目立刻得到可旋转的
准确图形，帮助理解题意、检验思路；
- **教师/同学**：课堂展示或小组讨论时，不再依赖静态 PPT 图，任何视角都能现场转到。

**一句话价值主张**：把"读题脑补图"变成"看题即得图"。
